Download the Lana desktop app for your computer:

| Your computer | Download |

| Mac with Intel | [Lana for Mac (Intel)](https://github.com/frain-dev/lana-releases/releases/latest/download/Lana-macos-x64.zip) |
| Windows | [Lana for Windows](https://github.com/frain-dev/lana-releases/releases/latest/download/Lana-windows-x64-setup.exe) · [ARM PCs](https://github.com/frain-dev/lana-releases/releases/latest/download/Lana-windows-arm64-setup.exe) |

| Linux (arm64) | [Debian package](https://github.com/frain-dev/lana-releases/releases/latest/download/Lana-linux-arm64.deb) · [AppImage](https://github.com/frain-dev/lana-releases/releases/latest/download/Lana-linux-arm64.AppImage) |

Not sure which Mac you have? Open the Apple menu → **About This Mac**. "Apple M1" or later means Apple silicon.

## Install

- **Mac:** unzip the download and move **Lana.app** to your Applications folder.
- **Windows:** run the installer, then open Lana from the Start menu. If Windows shows a SmartScreen warning, choose **More info → Run anyway**.
- **Linux:** install the `.deb` with your package manager, or make the `.AppImage` executable and run it.

Open Lana and sign in with your Lana account. To update, quit Lana and install the new version; your chats and settings are kept.

See [all releases](https://github.com/frain-dev/lana-releases/releases) for what's new in each version.
