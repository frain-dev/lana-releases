# Lana desktop downloads

Private preview builds for team testing and feedback.

[Download the latest preview](https://github.com/frain-dev/lana-releases/releases/tag/v0.1.0)

The current preview supports Apple Silicon Macs running macOS 13 or later. Download `Lana-macos-arm64.zip`, unzip it, and move **Lana.app** to Applications. Sign in with your Lana account.

The Mac app is Developer ID signed, notarized by Apple and stapled for Gatekeeper verification. A SHA-256 checksum accompanies each download.

Repository access is required to view and download these private releases. Share feedback with the Lana team before public distribution.
